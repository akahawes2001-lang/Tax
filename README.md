axBel — Налоговый калькулятор Беларуси (2025–2026)
О проекте
TaxBel — это современный онлайн-сервис для быстрого и точного расчёта налогов физических лиц в Республике Беларусь. Семь видов налогов, актуальные ставки 2025–2026 годов, автоматический пересчёт, детализация со ссылками на Налоговый кодекс, экспорт результатов — всё доступно бесплатно и без регистрации.

Проект состоит из:

Бэкенда на FastAPI + PostgreSQL (чистая архитектура, асинхронные запросы, JWT‑авторизация)

Фронтенда на React 18 + TypeScript + Vite + Material UI (стилизованный UI, управление состоянием через React Context)

⚙️ Функциональные возможности (что уже реализовано)
1. Подоходный налог
Учёт зарплаты, дивидендов, доходов из‑за границы и от физических лиц.

Прогрессивная шкала 13% / 25% / 30% (пороги 350 000 и 600 000 руб.).

7 видов вычетов: стандартный (216 руб. при доходе ≤1308 руб.), на детей (63/120 руб.), на инвалидность (306 руб.), молодые специалисты (860 руб.), дети‑инвалиды (120 руб.), социальные (обучение, страховки), имущественный (для нуждающихся).

Детализация по месяцам, график доходов и налогов, блок «Ваша экономия».

2. Транспортный налог
Справочник марок и моделей автомобилей с автоподстановкой разрешённой массы.

Расчёт для легковых, электромобилей (льгота 0 руб.), мотоциклов, прицепов, грузовиков и автобусов.

Налог на роскошь (×10) для автомобилей не старше 3 лет из перечня.

Группировка транспортных средств по типам с промежуточными итогами.

3. Налог на собак
Умный поиск породы с автоматическим определением категории «опасная / неопасная».

Ставки: опасные породы — 67 руб./квартал, неопасные — 14 руб./квартал.

Льготы: освобождение для инвалидов I/II группы, скидка 50% для пенсионеров и многодетных семей.

Добавление нескольких собак с разными породами.

4. Налог на вклады (депозиты)
Расчёт налога на проценты для вкладов в BYN, USD, EUR.

Освобождение для долгосрочных вкладов (BYN ≥ 1 года, валюта ≥ 2 лет).

Прогрессивная ставка 25% при годовом доходе свыше 350 000 руб.

Визуальная шкала‑индикатор порога освобождения.

5. Налог на аренду жилья
Выбор населённого пункта из справочника с автоматической ставкой (Минск — 53 руб./мес., облцентры — 49 руб./мес., крупные города — 33 руб./мес., прочие — 20 руб./мес.).

Типы объектов: комната, гараж, машино‑место.

Учёт количества месяцев сдачи.

6. Налог с продажи имущества
Категории: автомобиль, недвижимость, ценные бумаги.

Вычет документально подтверждённых расходов либо фиксированный вычет 20%.

Освобождение для единственного жилья, продаваемого не чаще раза в 5 лет.

7. Удержания из заработной платы
Обязательный взнос в ФСЗН (1%) — отображается автоматически.

Профсоюзные взносы (три варианта).

Добровольное пенсионное страхование «3+3», страхование жизни, медицинское страхование.

Исполнительные листы (алименты, штрафы, кредиты) с индикатором предельного размера удержаний (20% / 50%).

🔧 Ключевые технические решения
Автопересчёт
Каждый шаг мастера формирует JSON-ключ из параметров.

Хук useDebounce (600 мс) + проверка на изменение через useRef.

Запрос к API только при реальном изменении.

История расчётов
Сохраняется на бэкенде при нажатии «Сохранить».

Страница /history загружает данные с пагинацией через GET /api/v1/history?page=&limit=.

Детальный просмотр — GET /api/v1/history/{id}.

Экспорт в PDF и XLSX реализован на фронтенде путём разбора details_json и формирования документа.

Неавторизованный пользователь перенаправляется на главную после закрытия окна входа.

Авторизация
JWT-токен хранится в localStorage и автоматически добавляется к запросам через Axios-интерсептор.

Контекст AuthContext проверяет валидность токена при старте через /api/v1/auth/me.

Если токен недействителен, он удаляется, и пользователь считается гостем.

Глобальное модальное окно AuthDialog управляется через контекст.

Профиль
Данные профиля (ФИО, УНП, аватар) сохраняются в localStorage под ключом taxCalcProfile.

Статистика подгружается с сервера (/profile/stats).

Вкладки «Данные», «Отзывы», «Безопасность» стилизованы под общий дизайн.

🎨 Дизайн и пользовательский опыт
Стиль: тёмный фон #030711, бирюзовый акцент #14B8A6 (основной), цвет второстепенного текста #6c7c9d, «стеклянные» карточки.

Адаптивность: корректное отображение на телефонах, планшетах и десктопах.

Тёмная/светлая тема: переключение через контекст, плавный переход.

Типичный путь пользователя:

Заходит на главную → видит логотип, описание, кнопку «Полный расчёт».

Проходит мастер (доходы, вычеты, собаки, транспорт, вклады, прочие доходы, результаты).

На вкладке «Результаты» видит итоговую сумму, круговую диаграмму, может сохранить расчёт в историю.

Регистрируется/входит → история расчётов доступна на отдельной странице, можно экспортировать расчёты в PDF и Excel.

В профиле видит статистику, управляет данными.

Предварительные требования
Python 3.11+

Node.js 18+

PostgreSQL 15+

Бэкенд
bash
cd tax-api
python -m venv venv
venv\Scripts\activate      # Windows (или source venv/bin/activate на Linux/macOS)
pip install -r requirements.txt
Создайте .env:
DATABASE_URL=postgresql+asyncpg://user:password@localhost:5432/tax_calculator
SECRET_KEY=ваш_секретный_ключ_для_JWT
CORS_ORIGINS=http://localhost:5173
python seed.py
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

bash
cd tax-frontend

Интерфейс доступен по адресу http://localhost:5173.
