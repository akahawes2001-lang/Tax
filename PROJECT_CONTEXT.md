# Налоговый калькулятор (Беларусь, 2025–2026)

## Стек
- Бэкенд: FastAPI (Python), SQLAlchemy async, PostgreSQL, JWT, pytest.
- Фронтенд: React 18 + TypeScript, Vite, Material UI, Recharts, pdfmake.

## Архитектура
- Бэкенд: папка `tax-api/`, роутеры (income, dog, transport, deposit, rental, crypto, property_sale, admin, auth, car_catalog, history, settlements), модели, схемы, сервисы.
- Фронтенд: `tax-frontend/`, компоненты шагов (Income, Pets, Transport, Deposit, OtherIncomes, Results), контексты (Auth, Tax, Theme), API-клиент.

## Что уже реализовано (основное)
- Все налоговые расчёты (подоходный с вычетами, транспорт, собаки, вклады, аренда, крипта, продажа имущества).
- Справочники (автомобили, породы собак, населённые пункты) – загружаются через скрипты.
- Аутентификация (JWT), админские эндпоинты, история расчётов (сервер + localStorage).
- Тесты (pytest для бэка, Playwright e2e для фронта).
- Тёмная/светлая тема, экспорт PDF/XLSX, подсказки, тултипы.

## Главные недочёты (приоритетные улучшения из плана)
1. **Динамический пересчёт «на лету»** – сейчас только транспорт обновляется без кнопки.
2. **Удержания** – требуется сделать обязательный взнос в ФСЗН (1%), варианты профсоюзных взносов, алименты, исполнительные листы, визуализацию «воронка зарплаты» (она есть) и динамический итог «на руки».
3. **Вклады** – фронтенд не передаёт годовой доход для прогрессивной ставки 25% (бэкенд готов).
4. **Сохранение профиля** – данные о детях, льготах, жилье не запоминаются между сессиями.
5. **Результаты** – нет сравнения сценариев (с вычетами / без, 2025 / 2026), полной детализации формул, экспорта в виде декларации.
